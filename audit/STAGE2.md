# Второй этап: медицинская доказательность и контекст

Дата: 2026-09-20. Исходный commit: 4cd93c16fe59151b43013dfb445fe37a7a46d3c1.

Пересчитано: 135 JSON-протоколов, исходно 57 без sources, 390 исходных тестов, включая 65 сценариев маршрутизации. После изменений локально 401 тест. Это техническая регрессия, не медицинская сертификация.

Медицинская проверка: 0 протоколов полностью, 23 частично (34 конкретных утверждения), 112 ожидают проверки по источникам. Реестр medical_evidence.json связывает каждый проверенный текст с SHA256 и конкретным разделом источника. Полная таблица — stage2_evidence.csv. Непроверенные пункты сохраняются и не обозначаются подтверждёнными. Полных текстов Kirk, Small Animal Surgery и Slatter для сверки глав/страниц нет; общие названия книг не приняты как подтверждение назначения.

Числовые лекарственные схемы найдены в двух протоколах: бабезиоз и FIP, 7 основных полей (повтор в источниках отдельно не считается). Два режима бабезиоза сопоставлены с CAPC. Пять полей FIP сопоставлены с ABCD 2026 Table 1; формулировки ремдесивира и EIDD-1931 уточнены. Диапазон ремдесивира относится к разным исследованиям и НЕ является единой схемой назначения. EIDD-1931 ограничен малой серией, не обозначается стандартом. Подтверждённые числовые параметры не означают проверку всех показаний, длительности, препаратов конкретного производителя, пересчёта концентраций и коррекций при коморбидности. Непроверенные/изменённые числовые мг/кг-поля исключаются из контекста модели; оригинал остаётся в JSON/git. Проверка не является универсальным анализатором всех возможных способов записи назначения и не запрещает модели генерировать собственные числа, поэтому также изменены инструкции и предусмотрены live-проверки.

Подтверждены воспроизводимые технические проблемы:
- Обрезание диалога несколькими обёртками до 8–12 сообщений, потеря ранних препаратов при продолжении. Единый предел 60; проверена гидратация после перезапуска. Предел остаётся конечным.
- Диспетчер получал предыдущие утверждения ассистента наравне с сообщениями владельца. Теперь получает владельца и отдельно помеченные прежние вопросы, но не утверждения модели.
- Маршрутизация не выбирала ЖКТ-кровотечение для естественного описания ухудшения и лекарственного взаимодействия. Добавлены алиасы и точечный составной приоритет.
- Draft/species терялись при формировании протокольного контекста, диагностика называлась проверенной без такой проверки. Метки сохранены, ложное обозначение снято.
- Инструкция требовала сначала выдавать дозу. Заменена разделением арифметики готового назначения и выбора нового лечения с проверкой исходных данных.
- Сравнение медицинской памяти называло пересказы модели лабораторными исследованиями. Теперь происхождение и предварительный характер явно передаются модели.

Точная причина старого ответа с 18 вместо 12 кг неизвестна: полной исходной переписки нет. Правила приоритета текущего веса, конфликта карточки, происхождения фактов и геолокации усилены. Переключение питомца проверено, прежний случай не передаётся новому. Новые тесты не изменяют данные клиентов.

Поиск клиник: web search обязателен в соответствующей ветке. Адрес/контакты и заявленные услуги должны подтверждаться, текущая доступность крови/хирурга — уточняться звонком. Прежняя геолокация не должна автоматически становиться текущей. Полной гарантии актуальности интернет-справочников нет.

Live-проверки выполняются qa/live_stage2.py в окружении Railway со временной SQLite, без чтения/изменения клиентских строк и без отправки Telegram-сообщений. Три варианта последовательного случая повторяются дважды, плюс проверка арифметики и отсутствующей концентрации. FIRST не содержит симптомов SECOND. Лексические smoke-критерии лишь предварительные: требуется отдельная оценка всех фактических ответов — отсутствие преждевременных симптомов, сохранение препаратов/анализов, отсутствие подмены веса, срочное направление после ухудшения, запрет ибупрофена, отсутствие непрошеных назначений, бюджета и геолокации. Итоги Railway/live будут сообщены после выполнения; этот файл фиксирует состояние перед деплоем.
